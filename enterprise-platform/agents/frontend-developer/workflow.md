# Workflow: frontend-developer
## Trigger
Khi có API Specs và Design Documentation.
## Input
Figma/Wireframes, OpenAPI.
## Steps
1. Setup project/module.
2. Tạo static UI.
3. Tích hợp API.
4. Tích hợp feature flags.
## Output
Code pull request.
## Error Handling
Build lỗi -> tự động fix theo logs.
## Handoff to Next Agent
Chuyển code cho code-reviewer và tester.
