# Workflow: business-analyst
## Trigger
Khi có Feature Request mới.
## Input
Tài liệu yêu cầu ban đầu (draft).
## Steps
1. Tiếp nhận và đọc tài liệu.
2. Áp dụng requirement-analysis skill.
3. Sinh ra User Stories và Acceptance Criteria.
## Output
Tài liệu requirement đã được chuẩn hóa.
## Error Handling
Thiếu thông tin -> Request thêm từ User qua Orchestrator.
## Handoff to Next Agent
Chuyển tài liệu cho solution-architect và ux-designer.
