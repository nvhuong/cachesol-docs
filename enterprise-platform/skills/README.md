# Skills Catalog

## Cách dùng
- Agents/workflows tham chiếu **`skills/enterprise/<alias>`** (ổn định).
- Alias trỏ tới skill chuyên môn dưới `architecture/`, `design/`, `development/`, `review/`, `testing/`.
