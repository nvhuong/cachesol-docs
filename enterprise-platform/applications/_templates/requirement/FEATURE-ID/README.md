# Template Requirement Feature

Copy toàn bộ thư mục này thành:

`applications/<miniapp>/requirement/<feature-id>/`

Đổi tên `FEATURE-ID` → id thực tế (kebab-case).

## Checklist sau khi copy
1. Điền `requirement.txt`
2. Thêm ảnh vào `images/` (nếu có)
3. Đăng ký vào `requirement/_index.md` của miniapp
4. Chạy pipeline (Orchestrator / `workflows/feature-development.yaml`)
