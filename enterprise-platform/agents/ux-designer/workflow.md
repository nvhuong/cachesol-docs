# Workflow: ux-designer
## Trigger
Sau khi Requirement Analysis hoàn thành.
## Input
Requirement, User Stories.
## Steps
1. Đọc requirement.
2. Thiết kế user flows.
3. Tạo wireframes và UI specs.
## Output
Design documentation.
## Error Handling
Nếu thiếu chi tiết requirement -> báo BA.
## Handoff to Next Agent
Chuyển cho frontend-developer và design-reviewer.
