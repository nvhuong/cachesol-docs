# Workflow: architecture-reviewer
## Trigger
Khi Solution Architect nộp tài liệu design hoặc ADR.
## Input
Architecture documents, ADRs.
## Steps
1. Đọc tài liệu.
2. Đối chiếu với Architecture Principles.
3. Trả kết quả review.
## Output
Approved/Rejected decision.
## Error Handling
Nếu thiếu thông tin, yêu cầu cung cấp thêm.
## Handoff to Next Agent
Solution Architect để sửa, hoặc API Architect để tiếp tục.
